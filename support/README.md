# Support Material

This folder is for non-runtime project material that supports the Funcleson Video Board but is not part of the live app.

- `support/docs/`: local PDF/DOCX guides and operational reference files
- `support/beer-posters/`: large design source files and exported poster images
- `support/reference-assets/`: tracked small reference assets that are useful context but not used by the live board

The live app itself remains the single-file board in `index.html`, plus runtime assets under `assets/`.
